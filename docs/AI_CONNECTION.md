# AI connection and Gemini

## Current status

The app contains a complete server-side tutor/quiz flow and database persistence, but no live AI service is configured. `AI_PROVIDER=disabled` is the default, and no child's data is sent to a model in that state.

Google's Gemini Developer API terms, checked October 24, 2026, exclude API clients directed towards or likely to be accessed by individuals under 18. This affects the intended child-facing app. An adult-owned API key or paid Developer API tier does not remove that use restriction. Google Cloud's service-specific terms also contain generative-AI age restrictions; do not assume a Vertex AI switch solves it without verifying the applicable contract.

Primary sources:

- https://ai.google.dev/gemini-api/terms
- https://cloud.google.com/terms/service-terms
- https://ai.google.dev/gemini-api/docs/api-key

`lib/ai.mjs` contains a dormant `geminiAdultDevelopmentTest` adapter. It is not imported by a route or exposed in the child UI. Its purpose is development groundwork, not a working Gemini tutor for children. No live Gemini call was made during this build.

## Supported integration boundary

Once a provider/contract suitable for the children's ages and the application's data use is established, a trusted HTTPS gateway can implement this contract. The gateway is not included or deployed in this package; it is an integration boundary, not a claim of an already available provider.

The configuration is server-only:

```text
AI_PROVIDER=approved-gateway
AI_GATEWAY_URL=https://YOUR-TRUSTED-GATEWAY-ENDPOINT
AI_GATEWAY_KEY=YOUR-PRIVATE-GATEWAY-KEY
AI_MODEL=YOUR-SELECTED-MODEL
AI_GATEWAY_APPROVED_FOR_CHILDREN=true
```

The flag records a setup decision; it does not establish eligibility or override any service terms. Do not simply point the gateway at the excluded Gemini Developer API.

The app POSTs JSON to the configured URL with `Authorization: Bearer ...`:

```json
{
  "model": "configured-model",
  "mode": "chat",
  "max_output_tokens": 1200,
  "instructions": "Age-appropriate tutor instructions generated by the backend",
  "context": {
    "grade": "Grade from the student's record",
    "lesson": { "subject": "Selected subject", "name": "Selected lesson", "objective": "Imported objective" },
    "materials": [{ "title": "Imported source title", "summary": "Imported summary", "text": "Imported extracted text" }]
  },
  "messages": [{ "role": "user", "content": "The student's question" }]
}
```

Chat response:

```json
{ "text": "A concise explanation followed by one understanding check." }
```

Quiz mode uses `mode: "quiz"` and a 2,400-token requested output cap. Return:

```json
{
  "questions": [
    { "prompt": "Question one", "choices": ["A", "B"], "correct_index": 0, "explanation": "Why A is correct" },
    { "prompt": "Question two", "choices": ["C", "D"], "correct_index": 1, "explanation": "Why D is correct" },
    { "prompt": "Question three", "choices": ["E", "F"], "correct_index": 0, "explanation": "Why E is correct" }
  ]
}
```

The gateway must map trusted instructions separately from untrusted school text/student messages, enforce its own token cap and provider rules, return JSON, and keep secrets server-side. App validation rejects malformed question counts, choices and answer indexes before saving. It cannot prove the educational correctness of an AI-generated answer; parent review remains available.

## Progress and limits

- Tutor context comes from the authorized student/lesson and recent saved exchanges, not a caller-supplied student name or role.
- The application sends grade and lesson context; it does not automatically add the child's name, account email or family identifiers. A child can still type personal details, so the applicable service/data arrangements remain important.
- A failed model call is not saved as a completed exchange.
- Questions and responses are saved atomically only after a successful model response.
- The database enforces a shared tutor/quiz allowance of 5 requests per clock minute and 40 per UAE calendar day for the shared family Google account. Failed provider calls also consume an allowance slot.
- Chat history alone does not affect practice accuracy.
- A submitted practice answer is labelled assisted when a saved tutor reply for that student/lesson/child account exists in the prior 30 minutes. It cannot detect outside assistance.
- Objective answer grading does not make an inaccurate generated answer key accurate. Parent review is particularly important before relying on AI-generated practice.


## Version 2 practice types and Jarvis

Quiz requests now include `practice_type`, one of `mcq`, `fill_blank`, `short_answer`, or `matching`. All responses still contain exactly three questions. Each question includes `kind`, `prompt` and `explanation`.

- `mcq`: `choices` (2–4 distinct strings) and zero-based `correct_index`. Omitted kind defaults to mcq for the original contract.
- `fill_blank`: `choices: []`, `expected_answer` as 1–10 accepted strings. Database matching normalizes case and whitespace.
- `short_answer`: `choices: []`, `expected_answer` as a model-answer string, and `rubric` for the parent. The submitted answer remains pending and does not affect accuracy until parent review.
- `matching`: `choices: []`, `details: {left: [...], right: [...]}` with 2–5 distinct labels in each side, and `expected_answer` as a valid permutation of zero-based right-side indexes, one for each left label.

New material is eligible for grounding only after readable text is reviewed and marked ready. The server never treats an uploaded filename or a portion title as evidence that a school lesson was read.

Jarvis uses the same authorized tutor endpoint as typed lesson help. The orb/voice panel is an interface, not a separate model. Browser speech may involve an online vendor service and is not promised to operate offline. End/Close/profile changes stop local microphone/speech activity. See JARVIS.md.
